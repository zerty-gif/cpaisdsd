# cpaisdsd

Python project with security and networking tools.

## Requirements
- Python 3.13+
- Virtual environment

## Installation
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Libraries
- scapy
- paramiko
- netmiko
- psutil
- requests
- beautifulsoup4
- pwntools
- cryptography
- impacket
